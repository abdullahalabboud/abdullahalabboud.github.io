# Abdullah Alabboud — Portfolio

Personal portfolio of Abdullah Alabboud, Computer Engineer (AI & Simulation Developer).

Live: https://abdullahalabboud.github.io

- Static site: plain HTML, CSS and JavaScript, no build step.
- Languages: English, Arabic (RTL) and Turkish. Switch with the EN / ع / TR buttons, or open `?lang=ar` / `?lang=tr`.
- Text for all three languages lives in `js/i18n.js`.
- Profile photo: put it at `assets/profile.jpg` and replace the placeholder in `index.html`.
